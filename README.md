# School Office Hub

A Nigeria-first digital operations platform for schools and organisations. It focuses on document control, staff submissions, review workflows, digital filing and a separate public opportunity network—not traditional attendance, fees or result management.

## Current prototype

- Responsive dashboard for desktop and mobile
- Submission requirements with progress and status tracking
- Search and status filters
- Working new-request flow with local in-session updates
- Digital document cabinet
- People and role overview
- Separate opportunity network
- Installable Progressive Web App foundation

## Run locally

Serve the repository with any static web server. For example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.
